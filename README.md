# 六月里烘焙 · 好评小助手

扫码 → 现场生成 10 条好评 → 挑一条复制 → 粘到抖音订单页。
**纯前端单文件，无后台、无数据库、无登录。**

## 线上地址

https://pengfer.github.io/liuyueli-review/

二维码：`二维码/六月里烘焙-好评小助手.png`

---

## 它是怎么工作的

1. 客人扫码打开页面
2. 页面**当场拼接生成 10 条**好评（语料取自本店真实 5 星好评的用词习惯）
3. 客人挑一条 → 点「复制这句」→ 提示「已复制成功啦」
4. 客人粘到抖音/点评/美团订单页的评价框里

没有喜欢的，点右上角「换一批 ↻」，重新生成 10 条。

## 文案是怎么拼出来的

从 5 个语料池随机组合，再按 8 种句式模板拼装：

| 池 | 例子 |
|---|---|
| 开场（谁来的） | 和好朋友一起来做蛋糕 / 周末带娃过来的 / 团购来的 |
| 服务（本店招牌） | 小姐姐全程耐心指导，手残党也不会翻车 |
| 商品 | 动物奶油一点不腻 / 夹心水果给得足 / 四寸刚好两个人吃 |
| 环境 | 装饰可爱随手出片 / 窗边能看到 IFS 那只爬墙熊猫 |
| 收尾 | 成就感满满 / 性价比真的高 / 下次想带妈妈来 |

硬约束：

- **≥30 字**（实际 50~100 字）
- **不出现店里没有的商品**（只用蛋糕 4/5/6 寸、裸蛋糕、饼干、曲奇、雪花酥）
- **不写错误地址**（店在第一城 B 座，窗边能看到 IFS 爬墙熊猫）
- 同一批内不重复；换一批与上一批也不重复

## 改内容 / 改配色

全部在 `index.html` 里，改完重新上传即可：

| 想改什么 | 搜什么 |
|---|---|
| 店名、标语 | `六月里烘焙`、`挑一句最像你的` |
| 语料池 | `const OPEN` / `STAFF` / `GOODS` / `ENV` / `CLOSE` |
| 句式模板 | `const SHAPES` |
| 每批条数 | `generate(10)` 里的 10 |
| 配色 | 顶部 `:root` 的 `--pink-*`、`--rose` |
| 卡片上的小标签 | `const TONES` |

## 更新线上版本

改完 `index.html` 后，两种方式任选：

**方式一（网页）**：仓库 → `index.html` → 右上角铅笔 → 粘贴新内容 → Commit changes

**方式二（本地 git）**
```powershell
cd "E:\dshWorks\六月里烘焙-上线包"
git add -A
git commit -m "update"
git push
```

推上去约 1 分钟自动重新发布，网址不变（GitHub Actions 自动部署）。

## 边界

- ❌ 不自动发评价、不刷单、不诱导好评返现
- ✅ 只做一件事：让真实到店的客人，把本来懒得写的好话更容易写出来
- 文案是给客人**抄改**的，客人改两个词就是真的
