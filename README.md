# 六月里烘焙 · 好评小助手

一个给到店客人用的手机网页：**挑一句现成好评 → 一键复制 → 跳去抖音/点评/美团粘贴**。
纯静态单文件，不用服务器、不用数据库，传上 GitHub Pages 就能扫码用。

## ✅ 已经上线了

**网址：** https://pengfer.github.io/liuyueli-review/

二维码在 `二维码/六月里烘焙-好评小助手.png`，打印出来贴桌上即可。

- 后台入口：连续点顶部 🎂 或店名 **3 下** → 密码 `8888`

## 一、5 分钟上线（GitHub Pages）

### 1. 建仓库
- 打开 https://github.com/new
- 仓库名随便起，比如 `liuyueli-review`
- 选 **Public**（私有仓库的 Pages 要付费）
- 建好以后，把本目录里的 **`index.html` 上传进去**（拖拽上传即可，不需要 `.gitignore`、不需要构建）

### 2. 开 Pages
- 仓库 → **Settings** → 左侧 **Pages**
- Source 选 **Deploy from a branch**
- Branch 选 **main**（或 master）+ 目录 **/ (root)** → **Save**
- 等 1~2 分钟，页面顶部会出现网址：

```
https://<你的用户名>.github.io/liuyueli-review/
```

### 3. 变成二维码
- 用任意二维码工具（草料、微信自带、剪映都行）把上面这个网址生成二维码
- 打印出来贴在收银台 / 每张桌子上，或者放进核销后的欢迎语

> 域名是 `github.io`，国内访问**有时**会慢或间歇性打不开（不是墙，是 GitHub 的 CDN 在国内不稳定）。
> 如果店里网络访问不顺，建议配一个自定义域名（阿里云/腾讯云买个几十块的域名，CNAME 指过去），访问会稳很多。

## 二、客人怎么用

1. 扫桌上的二维码，打开页面
2. 看列表，挑一句顺眼的
3. 点「复制这句」→ 文案进剪贴板，这条自动从可选列表里消失（不会再有第二个人拿到同一句）
4. 弹出小窗，点「抖音 / 大众点评 / 美团」，App 会直接拉起
5. 在订单页找到「写评价」，长按输入框 → 粘贴 → 发出去

## 三、后台（改文案的地方）

**入口是隐藏的**：在首页连续点 3 下顶部的 🎂 或者店名，就会弹出密码框。

| 默认密码 | 8888 |
|---|---|

进去能做这些事：

| 功能 | 说明 |
|---|---|
| **新增一条好评** | 粘贴你自己写的/从别处看到的好句子，至少 30 字 |
| **自动补充 5 条** | 从真实好评里拆句重组，不编造店里没有的商品（4寸/5寸/6寸蛋糕、饼干、雪花酥这些） |
| **删除 / 恢复** | 删掉不想要的；「已被复制」的可以一键恢复，让客人重新看到 |
| **每天最多展示 N 条** | 默认 15。防止一个客人把整库都翻完、也避免同一个人反复取用 |
| **管理密码** | 改掉默认的 8888 |
| **导出 / 导入 JSON** | 换手机、换电脑时把库搬过去 |

> 后台数据存在**客人自己手机的浏览器**里（localStorage），所以：
> - 老板在自己手机上改的文案，**不会**同步到客人手机上
> - 客人「已复制」的记录也只在客人自己手机里
> - 想全店统一改文案 → 直接改 `index.html` 里 `<script id="seed">` 那段 JSON，重新上传

## 四、想换店名 / 换文案 / 换颜色

全部在 `index.html` 里，改完重新上传即可：

| 要改什么 | 找哪里 |
|---|---|
| 店名、标语 | 搜 `六月里烘焙`、`谢谢你喜欢这里` |
| 卡片文案 | 搜 `<script id="seed"`，里面是一个 JSON 数组，`text` 就是文案，`cat` 是分类标签 |
| 配色（淡粉主题） | 顶部 `:root` 里的 `--pink-*`、`--rose` 这几个变量 |
| 分类标签 | JS 里 `renderTags` 函数的 `const cats = [...]` |

## 五、这个工具不做什么（重要）

- ❌ 不自动发评价，不自建账号，不刷单
- ❌ 不诱导「好评返现 / 送东西换五星」——这是抖音平台规则和《反不正当竞争法》都明令禁止的
- ✅ 只做一件事：**让真实到店的客人，把本来懒得写的好话，更容易地写出来**

所以：文案是给客人**抄改**的，不是给机器人用的。客人手里那一句，只要他改两个词，就是真的。
